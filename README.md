# BMC Email Campaign Assets

This repository hosts the public image assets used by the 26-email BMC Pipedrive campaign.

## Structure

- `docs/images/` — hosted campaign images
- Pipedrive HTML templates reference the images using public `raw.githubusercontent.com` URLs.

## Live links

- Main campaign artwork links to the relevant page at https://www.bmc-ltd.co.uk/
- Phone links use `tel:01912284980`
- Email links use `mailto:helpdesk@bmc-ltd.co.uk`

GitHub Pages is not required for the Pipedrive templates because the images are served directly from the public repository.
